# OpenVision-RU — инструкция по установке

Русская сборка [OpenVision](README.md) для очков Meta Ray-Ban Gen 2: голосовой ассистент на
базе GigaChat (Сбер), с поддержкой русской речи (Apple STT/TTS) и режимом теста без очков
(камера iPhone / выбранное фото). Сборка неподписанная — устанавливается через Sideloadly.

Подробности решений и архитектуры — в [PLAN.md](PLAN.md) и [NOTES.md](NOTES.md).

---

## 1. Установка IPA через Sideloadly

1. Откройте вкладку [Releases](../../releases) этого репозитория (или Actions → последний
   зелёный прогон `Build`) и скачайте `OpenVision-unsigned.ipa`.
2. Подключите iPhone к компьютеру по кабелю. На телефоне подтвердите «Доверять этому компьютеру».
3. Откройте [Sideloadly](https://sideloadly.io):
   - перетащите скачанный `.ipa` в окно Sideloadly;
   - укажите Apple ID, которым будете подписывать (см. PLAN.md, раздел 1.4 — лучше отдельный,
     бесплатный Apple ID);
   - нажмите **Start**. При запросе двухфакторного кода — введите код с доверенного устройства.
4. На iPhone: **Настройки → Основные → VPN и управление устройством** → найдите профиль
   разработчика с вашим Apple ID → **Доверять**.
5. Если пункта **Настройки → Конфиденциальность и безопасность → Режим разработчика** ещё нет —
   он появится после первой установки через Sideloadly. Включите его, телефон перезагрузится,
   переустановите IPA ещё раз тем же способом.

## 2. Первый запуск

1. Откройте OpenVision → **Settings → AI → Настройки Сбер (GigaChat)**.
2. Вставьте **Authorization Key**, полученный на developers.sber.ru (см. PLAN.md, раздел 1.3).
   Ключ хранится только на телефоне — никуда, кроме GigaChat API, не отправляется.
3. Нажмите **Проверить подключение** — должно появиться «Подключение успешно» с числом доступных
   моделей. Если ошибка — см. раздел «Частые ошибки» ниже.
4. По умолчанию бэкенд «Сбер (GigaChat)» уже выбран, фраза активации — **«Окей, очки»**
   (Settings → Voice Control, можно изменить).

## 3. Тест без очков (пока они не пришли)

Settings → **Источник кадра**:
- **Камера iPhone** — очки не нужны вообще, кадр снимается камерой телефона по голосовой команде
  (без предпросмотра — это ожидаемо).
- **Выбрать фото** — один раз выбираете фото из галереи, дальше каждая команда «что это»/«что я
  вижу» отвечает по этому же фото. Удобно для проверки самого пайплайна GigaChat.

Скажите **«Окей, очки, что это?»** — должен прозвучать ответ на русском.

## 4. День прихода очков — регистрация

1. Установите приложение **Meta AI** на iPhone (через VPN, если App Store требует другой регион),
   войдите аккаунтом Meta.
2. Сопрягите очки с iPhone через Meta AI (Bluetooth).
3. В Meta AI: **Settings → About** → 5 раз тапните по номеру версии → включите
   **Developer Mode**.
4. В OpenVision: **Settings → Glasses → Register App** — откроется Meta AI, подтвердите доступ,
   вернитесь в OpenVision.
5. Settings → Источник кадра → выберите **«Очки»**.
6. Проверка: «Окей, очки, что я вижу?», «Окей, очки, прочитай».

Если очки не регистрируются — откройте **Settings → Диагностика**, проверьте статус
регистрации/устройств и пришлите этот экран (без ключей — там их и нет) в Claude Code для разбора.

## 5. Переподпись раз в 7 дней

Бесплатный Apple ID подписывает приложение на 7 дней. Когда приложение перестало открываться
(значок есть, но при запуске сразу закрывается) — переустановите **тот же** `.ipa` тем же
способом (раздел 1). Данные и настройки (ключ GigaChat, фраза активации и т.д.) сохраняются —
Sideloadly не удаляет Documents-хранилище приложения при переустановке той же сборки.

## 6. Обновление на новую версию

Каждый пуш в `main` пересобирает `OpenVision-unsigned.ipa` (см. вкладку Actions). Скачайте новый
файл и установите его тем же способом через Sideloadly — данные приложения сохранятся.

## 7. Частые ошибки

| Симптом | Причина / что делать |
|---|---|
| «Ошибка GigaChat (HTTP 401)» при «Проверить подключение» | Неверный или просроченный Authorization Key — перевыпустите на developers.sber.ru |
| «Закончился лимит токенов GigaChat» (HTTP 402) | Исчерпан лимит Freemium (25 млн Max / 40 млн Pro за 12 мес) — см. PLAN.md, раздел 7 про cloud.ru |
| Таймаут / ошибка TLS при обращении к GigaChat | Включён VPN — для GigaChat он не нужен и может мешать; выключите VPN или добавьте домены `*.sberbank.ru` в исключения |
| Приложение при запуске сразу закрывается | Истекла 7-дневная подпись — переустановите тот же `.ipa` (раздел 5) |
| «Confirm developer» не помогает, приложение не открывается | Профиль не доверен: Настройки → Основные → VPN и управление устройством → доверять профилю ещё раз |
| Очки не находятся при регистрации | Bluetooth выключен или очки не сопряжены в Meta AI; Developer Mode не включён (раздел 4, шаг 3) |
| «Configuration Invalid» / регистрация очков зависает | В форке ещё не настроены `META_APP_ID`/`META_CLIENT_TOKEN` (GitHub Secrets) — до их добавления работает только Developer Mode с заглушками, реальная регистрация очков недоступна (см. PLAN.md, раздел 1.5) |
| Нет звука в очках | Проверьте, что очки выбраны как аудио-устройство в настройках Bluetooth iPhone |
| Распознавание фразы активации срабатывает неточно | Фраза «Окей, очки» и её варианты не проверялись на реальном железе — можно изменить фразу в Settings → Voice Control; сообщите Claude Code примеры неверных срабатываний для донастройки |

## 8. Смена ключа / выход

Settings → Настройки Сбер (GigaChat) → очистите поле Authorization Key → Сохранить. Ключ хранится
в обычном файле настроек приложения (не в Keychain — см. NOTES.md, раздел 7), как и остальные
ключи в этом проекте.
