# tools/

Вспомогательные скрипты, не входящие в iOS-приложение.

## gigachat_smoke.py — смоук-тест GigaChat API

Проверяет всю цепочку GigaChat API (OAuth → список моделей → загрузка файла →
чат с изображением → удаление файла) с обычного Windows-компьютера, без Xcode,
до того как писать Swift-код в Фазе 3b.

### Запуск (PowerShell)

VPN **выключить** (или добавить домены `*.sberbank.ru` в исключения) — GigaChat
работает без VPN, а через VPN может не пройти проверка TLS.

```powershell
pip install requests
$env:GIGACHAT_AUTH_KEY = "<ваш Authorization Key с developers.sber.ru>"
python tools\gigachat_smoke.py
```

Ключ вводится **только в эту переменную окружения в вашем собственном терминале**
— никогда не вставляйте его в чат с Claude Code, в код или в коммиты.

### Что делает скрипт

1. Получает access token по Authorization Key (`POST /api/v2/oauth`).
2. Запрашивает список доступных моделей (`GET /api/v1/models`).
3. Загружает `tools/test.jpg` (`POST /api/v1/files`).
4. Отправляет изображение в `GigaChat-2-Max` (`POST /api/v1/chat/completions`)
   с вопросом «Что изображено на этой картинке?» и печатает ответ на русском.
5. Удаляет загруженный файл (`POST /api/v1/files/{id}/delete`).

Ключ и токен целиком в вывод не печатаются — только длина токена.

### Сертификат

Скрипт использует `certs/russian_trusted_root_ca.pem` (корневой сертификат
НУЦ Минцифры России) для проверки TLS-соединения с `*.sberbank.ru` — это
публичный сертификат, специально закоммиченный в репозиторий.

### Если что-то пошло не так

- `ОШИБКА: OAuth не удался: HTTP 401` — неверный или просроченный ключ.
- `HTTP 402` — закончился лимит токенов Freemium.
- Таймаут / SSL-ошибка — проверьте, что VPN выключен, либо домены Сбера
  добавлены в исключения VPN.
